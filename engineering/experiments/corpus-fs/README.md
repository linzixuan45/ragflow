## 口径纪律（判读任何数字前必读）

- 判定用 `warm_p50` + `mdd_robust`（抗尾）；**`tail_events` 增加即视为回归**。尾部是混合体，必须同时看阶段分布与进程 CPU 以区分「在算」与「在等」。
- **V0 在新协议下不可得**（代码已被 V1~V3.8 覆盖），其指标一律是旧口径。
- 旧口径的 `L(12)` / `L(16)` 与新口径**不可直接比较**：旧「12 库」实为 8 个互异语料（含逐字节相同的重复库）。
- `L(4)` **不可判定**（噪声地板 CV 0.686），不得用于判定改善/回归。
- 采样表已改为 12 个互异库，库数梯度去掉了 16 档。

## 维护规则

Corpus FS / 多库检索相关改动，每次都要留下**三件套**：实验数据 + Markdown 版本记录 + 影响面；原始数据落 `baseline/`，并同步 `records/README.md` 的版本索引表。**缺必填指标不得标「采纳」。**
