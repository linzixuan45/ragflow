# 试验 — 重排控制通道修正：前缀缓存使"直连 p50"失真（2026-10-01）

> 性质：**不改代码的验证/方法学修正**（README §1：记为 `VX-试验`）。
> 触发：本轮排查"16 库 rerank HTTP 1.68s vs 直连同形状 0.35s"的 5 倍差异。
> 结论：**该差异不是客户端、不是服务漂移、也不是 payload 大小，而是直连对照用了带公共前缀的合成文档，被 vLLM 前缀缓存加速**。原分析 §3.8/§8.1 的"重排服务直连 p50 0.16s vs 路径内 0.6~1.7s"因此**不是未解之谜，而是对照失真**。

---

## 1. 排查过程（每一步都用同一时刻的对照）

| 假设 | 实验 | 结果 | 判定 |
|---|---|---|---|
| 客户端（cohere SDK / 连接新建） | 同一真实 payload 依次用：新建 cohere 客户端、复用客户端、共享 httpx、重建的 in-app 模型 | **四者全为 1.68s** | ❌ 排除 |
| 服务端漂移 | 检索运行**同时**从宿主机直连同一服务（127 文档同形状） | 并发窗口内直连稳定 **0.35s**，而路径内 2.03s | ❌ 排除 |
| payload 大小 | 抓取真实请求体 | 真实体 **53~64KB**；直连对照体更大（~90KB）却快 5 倍 | ❌ 排除 |
| 本地分词器低估导致超长 | 逐文档对比本地 `num_tokens_from_string` 与服务器 `/tokenize` | 本地 **高估**（server/local p50 = 0.60），127 篇**没有一篇**超过 768 预算 | ❌ 排除 |
| **前缀缓存** | 同样 127 篇、同样约 9 万 token：一组共享长前缀 vs 一组**内容互异** | 共享前缀 **0.35s**；互异内容 **4.32s** | ✅ **成立** |

且内容按比例截断的曲线同样吻合（真实 payload）：`factor=1.0 → 1.70s`、`0.5 → 0.38s`、`0.25 → 0.22s`、`0.125 → 0.20s`——即成本随**真实唯一 token 量**走。

---

## 2. 影响：控制通道（M7）的绝对数值不可用于判断"路径内是否异常"

- 采集协议里的控制通道是「直连 rerank 80 文档 × 20 次」，其文档是同一段合成文本（`scripts/baseline/collect_baseline_http.py` 的 `rerank_control`）→ **命中前缀缓存**，p50 长期稳定在 0.158s。
- 真实检索的候选是**互异**的库内文本 → 无前缀可复用，16 库 127 篇约 3.98 万真实 token 需要 1.7~2.0s。
- 因此：
  1. **不能**用"控制通道 p50 0.158s 没变"来论证"服务端没问题"；
  2. 原分析 §3.8/§8.1 里"路径内比直连慢 4~10 倍"的现象**得到解释**，不是集成缺陷；
  3. 原分析 §6 里"重排 0.16s vs 960 文档 12.99s 的超线性"也需重读——0.16s 那组很可能受益于前缀缓存。

**修正后的判据**：控制通道只用于判断"服务是否在响应"（次数/可用性），**不再用于跨版本比较单次重排耗时**。跨版本比较一律用**同一条真实 query 的原位计时**（`phase_fused_recall.py` 的 `rerank.http`）。

---

## 3. 协议 v3 增补（写回计划 §2）

| 项 | 变化 |
|---|---|
| M7 控制通道 | 保留，但**只作可用性/量级参考**；文档改为**互异内容**（前缀缓存不可复用）才可用于耗时对照 |
| 跨版本比较 | 用同一 query 的原位 `rerank.http` / 各阶段秒数（配对、同位置） |
| 报告要求 | 涉及重排的版本必须同时给出「候选数 + 真实 token 总量」，否则无法解释耗时差异 |

## 5. 结论对本计划的影响

1. **D（池预算）依据被坐实**：重排成本 ≈ 合并池的**真实唯一 token 量**，而非文档数。16 库池 127 篇 ≈ 3.98 万 token ≈ 1.7~2.0s。预算应按 token 估。
2. **"重排服务很慢"的旧结论作废**：服务本身吞吐正常（互异内容 127 篇/8.9 万 token 约 4.3s，即 ~2 万 token/s；真实池 3.98 万 token 约 1.7s 与之吻合）。
3. 后续版本记录若涉及重排，必须报「候选数 + token 量 + 原位耗时」三件套。
